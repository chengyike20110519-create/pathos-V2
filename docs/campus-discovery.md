# 校园漫游 · 本地接入说明

更新日期：2026-10-21

## 入口与动线

- 本地预览：`http://localhost:3002/discover`。
- 首页首屏「还没目标？逛逛校园」、首页校园卡区、找学校菜单「校园漫游」、地图工具栏「随便逛逛」。
- 每期展示6所学校，北京时间每天零点换一批；同一天刷新保持一致，不再在漫游区无限加载94校。
- 卡片以每秒28像素缓慢横移，到两端平缓折返，不复制可点击卡片，也不突然跳回开头。横滑、触控板、鼠标拖动或方向按钮仍可自由切换。
- 悬停、键盘焦点进入、触摸拖动、翻开简介或打开学校档案时暂停；方向按钮、触控板操作后留出6秒阅读时间。提供「暂停漫游／自动漫游」开关。
- 切到后台或滚出视口时停止动画；系统要求减少动态效果时默认不自动滚动。跨日更新若遇到正在阅读，等退出阅读后再换，不抢走当前卡片。
- 明确的读简介按钮负责翻面，两种手势互不抢占。
- 背面保留约100–150字的总体概括和可展开来源。点击「打开大学信息卡」复用已有的学校详情、专业及来源面板；关闭后回到原卡片。
- 校园建筑照片作为主视觉；本版不额外抓取或伪造校徽。不按排名排序，也不把照片审美当作择校结论。

## 组件与数据

- 使用React Bits官方 `FlipCard-JS-CSS`，通过shadcn CLI安装，依赖Motion；实际组件名不是`undefined`。
- 上游源码、CSS及许可放在`frontend/src/components/reactbits/`；对受控模式的指针事件、嵌套键盘控制、React 18的inert属性做了小幅适配。
- 学校身份与已审核、许可已核验的校园照片来自Supabase，只取每校第一张展示照片，不读取完整专业档案。
- 新概括来自服务端审核资料`frontend/data/reviewed/university-overviews.json`，未写入Supabase，也不直接导入浏览器组件；来源读取方式仍明确区分正文与检索摘要。
- 2所简介全部依据官方检索摘要，另4所有部分摘要依据；界面显示对应复核提示，不假装已全文核验。
- 没有照片或图片请求失败时显示明确缺失提示，不替换成其他大学或生成照片。

## 载入策略与实测边界

- 统一沿用`PathOSDataSource`和预览BFF，新增`campus-discovery`端点。
- 漫游页面只请求当期6所的轻量卡片，没有「继续加载」或遍历全部学校。按固定非排名顺序每天前进6校，当前94校在连续16期内均可出现；相邻两期不重复（前提是学校池至少12所）。学校仍完整保留在地图与搜索中。
- 底层接口保留每页最多12所的通用分页兼容性；八页94个唯一ID、94条照片记录和94篇简介的记录覆盖测试仍保留。这不代表94张图片逐个下载验收。
- 同一快照只发一条轻量数据库查询，服务端五分钟缓存并合并并发请求；Next数据缓存跨模块重载复用，简介内容哈希变化时失效。
- 前两张照片优先读取，其余图片懒加载；完整大学档案在点击信息卡时才请求。首页漫游动画模块靠近视口后才下载。
- 每个翻转卡片独立记忆状态，并避免随浏览计数改变全部重新渲染。尊重系统减少动态效果设置。
- 本地开发接口实测首组约18.6 KB，暖缓存约15毫秒；冷连接观测到约7.3秒、13.6秒，包含开发编译/连接成本，不代表生产首屏性能。外部图片下载与浏览器渲染不包括在接口计时中，不能承诺所有用户秒开。
