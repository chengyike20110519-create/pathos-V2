### 1.4 报告页深度【已验证·雅思 0 基础】

启德有完整报告矩阵：
- 2026 中国香港求学报告（连续 7 年）
- 2026-27 德国留学与求职趋势洞察
- 2026-27 新西兰留学与就业新趋势解读

- 2026 加拿大留学报告
- 雅思 0 基础速成手册（听/读/说/写四册）

报告结构：
1. 封面 + 试读
2. 报告摘要（300-500 字）
3. 数据来源说明（启德服务客户大数据 + 官方数据）
4. 完整报告需获取（手机号 → 短信验证码 → 完整 PDF）

**评估**：
- 报告有持续性（年/季度更新）
- 报告有数据底座
- 报告需手机号（转化导向）
- 没有"为各个学校画折线图"这种专项数据可视化

### 1.5 UI / UX 评估

- **设计风格**：Nuxt.js SPA + 蓝白主色 + 大 banner + 顾问头像矩阵
- **信息密度**：首页低（营销主导），学校详情页中高（数据密集）
- **信任锚点**：75 分中心 + 24W offer + 2000 顾问 = 规模信任
- **转化路径**：首页 → 工具 → 表单 → 顾问电话 → 1v1
- **典型交互**：点击"咨询申请方案" → 弹窗表单 → 顾问 15 分钟回电

### 1.6 PathOS v2 可借鉴 / 应避开

**借鉴**：
1. 学校详情页的字段结构（排名+费用+要求+校友+强势专业）—— v2 B1 学校深度可直接对标
2. 报告型内容（年度报告 + 系列手册）—— v2 可以做"美国 Top 30 留学报告"
3. 直播 + 视频矩阵 —— v2 可以做"政策解读直播"作为事件流入口
4. 双维度导航（国家 × 学历阶段）—— v2 学校端可用，并加"专业"维度
5. 明细费用表（学位 × 类型 × 最高/最低）—— v2 学校深度页可借鉴

**避开**：
1. 顾问头像矩阵 + 表单转化 —— 跟 PathOS 信息集合与展示定位冲突
2. 大 banner + 蓝白配色 —— 不是 v2 想要的"专业版工具"调性
3. 报告需手机号 —— v2 注重"公开可访问 + 数据可追溯"
4. 缺时序数据 —— 启德根本没做时序图，v2 B3 是绝对蓝海
5. 缺 verified 标记 —— v2 要做"verified by IECG / verified by US News / not verified"等标签

## 2. 新东方前途出国 liuxue.xdf.cn【已验证·中等】

### 2.1 核心定位
- **服务范围**：留学申请 + 求职就业 + 背景提升 + 学术指导 + 跨境服务 + 签证服务 + 小语种
- **规模**：48 直营分子公司 + 数千顾问
- **母公司**：新东方教育科技集团（NYSE: EDU）

### 2.2 信息架构

**方案包驱动**（核心差异化）：
- 尊享计划 / 启航计划 / 软实力成长（本科）
- 转学申请 / 低门槛进阶 / 常春藤工作室（本科）
- 微留学计划 / TOP30 申请（中学）
- 跃领计划 / 英领计划 / 牛剑营（英系）
- 贝勒比斯 / 跃领计划 / 私立寄宿（英系中学）
- 启航计划 / 优享计划（加拿大）
- 前途塾 / EJU 留考 / 英文授课（日本）
- 副学士 / 高端申请（香港本科）
- 考研双计划-中英/中美（研究生）

**工具清单**：
1. AI 智能选校
2. 留学费用计算
3. GPA 计算
4. 测评中心
5. 投资回报计算（**留学 ROI 工具**）
6. 知识库（问答库）
7. 求职就业

### 2.3 关键发现：投资回报计算（ROI）

新东方的**差异化亮点**：把留学做成 ROI 工具
- 输入：学校 + 学费 + 生活成本
- 输出：投资回收期

这是 PathOS v1 没做的功能，v2 可以**借鉴**。

### 2.4 UI / UX 评估

- **设计风格**：jQuery + 模板引擎（不是 SPA） + 红白配色 + 方案包卡片矩阵
- **核心交互**：城市选择 → 方案包 → 顾问咨询
- **没有**：学校详情深度页 / 时序可视化 / 专业级数据

### 2.5 PathOS v2 可借鉴 / 应避开

**借鉴**：
1. 方案包驱动（针对不同学生类型做方案）—— v2 学校端可以做"学校包"
2. 投资回报计算（ROI）—— v2 家庭端可以做
3. 方案 × 国家矩阵 —— v2 学校端导航可以借鉴
4. 全链条服务（留学 → 求职 → 签证）—— v2 不做 1v1，但可以做"流程时间线"

**避开**：
1. 方案包过度营销 —— PathOS v2 定位"信息集合与展示"，不是"申请服务销售"
2. 红白配色 —— 不是专业版工具调性
3. jQuery 模板引擎 —— 不是现代 SPA，v2 必须 Next.js 现代架构
