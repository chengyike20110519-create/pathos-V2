## 2. v2 启动版调整（基于竞品研究）

### 2.1 模块优先级调整

| 原优先级 | 新优先级 | 模块 | 调整理由 |
|---|---|---|---|
| P0 | **P0** | B3 时序可视化 | 0 竞品，用户原话直接命中 |
| P0 | **P0** | B1 学校深度 | 启德有 20+ 字段，v2 必须 30+ + verified + missing |
| P1 | **P1** | B2 专业对比 | 选校帝有 200+ 分类，v2 必须 50+ + 跨校对比 |
| P1 | **P1** | A5 第三方接入 | 建立权威数据底座 |

| P2 | **P2** | A2 专业级数据 | B2 启动时同步 |
| P2 | **P2** | A6 半自动爬虫 | S3 启动时再做 |
| P3 | **P3** | S3 新专业雷达 | 先做基础事件库 + 5-10 篇解读 |

### 2.2 学校详情页字段升级（B1）

**启德哈佛详情页有 ~20 字段，v2 必须 30+ 字段 + verified + missing**：

**基础字段（沿用启德）**：
- 中英文名 / 国家地区 / 院校类型 / 建校时间 / 学生人数
- QS / US News / THE 排名
- 学费（学位 × 类型 × 最高/最低）
- 住宿费 / 生活费 / 申请费
- 语言要求 / 标化要求
- 强势专业 / 学校简介 / 校友 / 设施

**增量字段（v2 独有）**：
- ✅ **verified 标签**：每个字段都标 source + asOf + verified（verified by IECG / verified by US News / not verified）
- ✅ **missing-first**：未知字段明确标"暂无数据"而非省略
- ✅ **时序入口**：每所学校详情页有"近 5-10 年变化"按钮 → B3 时序图
- ✅ **跨校对比入口**：每所学校的"对比"按钮 → B2 跨校对比表
- ✅ **新专业入口**：每所学校的"新专业"按钮 → S3 雷达
- ✅ **案例入口**：每所学校的"录取案例"按钮 → 案例库
- ✅ **专业级字段**：哈佛的 CS 招生 / 录取率 / 课程密度 → B2
- ✅ **缺失数据诚实标**：没有数据的不显示 0，显示"暂无"
- ✅ **数据更新时间**：asOf = "2024-08-15" 标注

### 2.3 B1 学校深度文章结构（每校 5 篇专题）

借鉴百利天下的"哈佛 / 斯坦福 / MIT 申请指南"模式 + 启德的学校详情页字段 + 选校帝的丰富数据：

1. **学校概览**（基于 IECG + 第三方数据 + verified）
2. **录取数据深度解读**（SAT / GPA / 录取率 5 年趋势 → 嵌入 B3 时序图）
3. **强势专业横向对比**（CS / 工程 / 商业 / 文科 + 跨校对比 → 嵌入 B2 对比表）
4. **校园生活 + 校友**（基于 IECG + 学校官网）
5. **新专业 / 政策变化**（嵌入 S3 雷达事件）

### 2.4 B2 专业对比内容结构（对标选校帝 200+ 分类）

每个专业（CS / 人类学 / 工程 / 商业 / 理科 / 艺术等）1 篇深度对比：

1. **专业概览**（学什么 / 适合谁 / 就业方向）
2. **学校排名**（US News + QS + IPEDS）
3. **跨校对比表**（招生人数 / 录取率 / 课程密度 / 学费 / 毕业薪资）
4. **跨校时序对比**（录取率 / 学费 5-10 年趋势图 → 嵌入 B3）
5. **申请建议**（GPA / SAT / 文书要求）
6. **录取案例**（被录取学生画像 + GPA / SAT / 文书片段）

**专业分类参考选校帝 7 大类**：
- 工科 / 商科 / 理科 / 社科 / 艺术与人文 / 农林 / 生命科学与医学
- v2 启动版先做 8-12 个主流专业（CS / 工程 / 商业 / 数学 / 物理 / 医学预科 / 心理学 / 教育等）

### 2.5 B3 时序解读内容结构（绝对蓝海）

每篇时序解读文章：

1. **主题**（如"近 5 年藤校录取率变化" / "SAT 标化政策变化对录取的影响"）
2. **数据图表**（折线图 / 时间线，多学校叠加）
3. **解读**（事件背景 + 趋势分析 + 影响评估）
4. **建议**（对家长 / 学生的具体行动建议）

### 2.6 S3 新专业雷达内容结构

1. **新专业事件流**（半自动爬虫 + 编辑审核）
2. **专业解读文章**（AI 起草 + 编辑改写）
3. **适合度分析**（哪些学生适合）
4. **数据来源 + verified 标签**

## 5. v2 商业模式调整

### 5.1 三种可能的商业模式

| 模式 | 描述 | 参考竞品 | PathOS v2 可行性 |
|---|---|---|---|
| **A. 信息集合免费 + 顾问付费** | 信息免费，深度解读 / 案例库付费 | 启德 / 新东方 | 中（深度内容付费点） |
| **B. 专业版订阅** | 学校端 / 家庭端双订阅 | 美世 / Notion / Bloomberg | **高（匹配"专业版"定位）** |
| **C. 数据 API / 白标** | 数据底座开放给第三方 | College Scorecard / IPEDS | 中（需要先有数据底座） |

**我的推荐**：**B（专业版订阅）**

理由：
1. 匹配"专业版工具"定位
2. 学校端订阅（顾问 / 老师按月付费）= 强付费意愿
3. 家庭端订阅（家长按年付费）= 中等付费意愿
4. v2 启动期可先做"学校端专业版"

### 5.2 v2 启动版商业化路径

**Week 1-8（骨架）**：0 收入，全部投入做产品
**Week 9-16（内容）**：免费版上线，积累种子用户（5-10 校顾问 + 家长群）
**Week 17-20（试用）**：学校端专业版试用（100-200 元/月）
**Week 20+**：正式版上线 + 家庭端高级订阅（299-499 元/年）

### 5.3 v2 启动版 ROI 估算

**资源投入（20 周）**：
| 资源 | 数量 | 周成本 | 总成本 |
|---|---|---|---|
| 前端 / 全栈 | 1 人（你 + 必要时外包） | — | 时间成本 |
| 主编 | 1 人（你自己） | 0（你的时间） | 0 |
| 编辑 | 1 人（兼职） | 2,000-3,000 元 | 40,000-60,000 元 |
| AI 起草 API | DeepSeek / GPT | 500-1,000 元 | 10,000-20,000 元 |
| 服务器 / 部署 | Vercel + Render | — | 5,000-10,000 元 |
| **总计** | — | — | **55,000-90,000 元** |

**收入预期（保守）**：
- Week 9-20：5-10 试用 → 月收入 500-2,000 元
- Month 4-6：30-50 学校端 → 月收入 3,000-10,000 元
- Month 7-12：100-200 学校端 + 50-100 家庭端 → 月收入 15,000-50,000 元

**盈亏平衡**：月成本 5,000-8,000 元 → 学校端 50 个付费用户 = 盈亏平衡
